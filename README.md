# SturdyFlow — Organizador de Estudos

## Sobre o trabalho

O SturdyFlow é um organizador de estudos desenvolvido em Python com Tkinter. Seu objetivo é auxiliar estudantes a organizar matérias, acompanhar tarefas e registrar sessões de estudo em uma única aplicação.

## Programas Usados

- Python 3.14.8
- Tkinter
- JSON para armazenamento dos dados
- Git e GitHub para controle de versão

## Funcionalidades

- Cadastro, listagem e remoção de matérias.
- Cadastro de tarefas vinculadas às matérias.
- Definição de prazos para tarefas.
- Marcação de tarefas como concluídas.
- Cadastro de sessões de estudo com data e duração.
- Dashboard com resumo das atividades.
- Salvamento e carregamento automático dos dados.

## Como executar

1. Instale o Python.
2. Clone ou baixe este repositório.
3. Abra a pasta do projeto no terminal.
4. Execute o comando:

```bash
python main.py
```

## Armazenamento

Os dados são armazenados localmente no arquivo `dados.json`, gerado automaticamente durante a utilização do programa.
